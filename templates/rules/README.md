# 規則層

一個主題一個檔，兩位數字前綴排序。規則寫**必須／不得**與**為什麼**，
不寫流程步驟 —— 流程屬於 skill。

一條規則要能回答：**違反它會發生什麼事。** 答不出來的不是規則，是偏好，
刪掉。

## 常駐 vs 按需

沒有 frontmatter 的檔案**每個 session 都會載入**。只在特定路徑下才成立的
規則要加 `paths`，讓它按需載入：

```markdown
---
paths: ["src/**/*.py", "eval/**/*.py"]
---

# 這條只在動到那些路徑時才載入
```

判準：**這條規則在任何檔案上都成立嗎？** 是 → 常駐；否 → 加 `paths`。

常駐規則會吃掉每個 session 的 context，所以「反正加著也沒差」是錯的 ——
清單越長，每一條被實際遵守的機率越低。
